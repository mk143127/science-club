What kind of project can we work on?

Start by checking the current WWSEF Exhibitor Manual. Common directions include engineering/design, software or apps, robotics, life science, chemistry, physics, mathematics and data-based studies. A coding project should still have a clear question, need, test or measurable outcome.

How to Use the Portal

New member? Start here.

1

Create a random username

Use something like AtomAce47, not your real name. Add a password so only you can use that account.

2

Check the Dashboard

See announcements, upcoming dates, your resource activity and quiz count.

3

Open Resources

Use CCC, WWSEF and general club materials. Resource opens are associated with your random username.

4

Use Project Lab

Check current WWSEF parameters, browse project idea websites and use the brainstorm helper before choosing a project.

5

Complete CCC Modules

Open CCC Modules for lesson notes, practice questions, short answers, checklists and resource activities. Your progress is saved.

6

Take CCC Quizzes

Choose a quiz, answer every question and submit. Your result and explanations appear immediately.

7

Check Calendar + FAQs

Use the Calendar for dates and FAQs for common questions. Admins can update portal content.
